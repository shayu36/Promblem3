# 任务 3：时间序列预测 —— 室外温度（OT）

《数据挖掘导论》2026 大作业·必做任务三。根据过去 2 小时（12 个时间点）的气象观测，
预测下一时间点的室外温度（OT）。

## 1. 环境配置

- Python 3.9+
- 依赖安装：

```bash
pip install -r requirements.txt
```

| 依赖 | 版本 | 用途 |
| ---- | ---- | ---- |
| numpy | >=1.24 | 数值计算 |
| pandas | >=2.0 | 数据读取与清洗 |
| scikit-learn | >=1.3 | 标准化、岭回归基线、指标 |
| torch | >=2.0 | LSTM / GRU 模型 |
| matplotlib | >=3.7 | 结果可视化 |

## 2. 数据说明

- 文件：`data/weather.csv`（GBK 编码，共 26200 行、22 列）
- 来源：德国某气象站，每 10 分钟记录一次，覆盖约半年
- 特征：`date` 时间列 + 21 个气象学指标（气压、温度、湿度、风速、辐射等）
- 目标：`OT`（室外温度），即预测下一时间点的 OT
- 注：原始数据中存在取值为 `-9999` 的传感器异常占位值，脚本会自动做时序线性插值清洗。

## 3. 运行方法

```bash
python main.py
```

脚本会自动完成：数据清洗 → 滑动窗口切分（窗口 12，即 2 小时）→ 特征标准化 →
按时间顺序划分训练/验证/测试集 → 训练多种子 GRU 集成与岭回归并在验证集上选择组合权重
→ 输出指标与可视化。

训练完成后，结果保存在 `results/`：

- `metrics.json`：各模型的 RMSE / MAE / R² / MAPE
- `loss_lstm.png`、`loss_gru.png`：训练曲线
- `prediction.png`：测试集预测值与真实值对比
- `scatter.png`：预测-真实散点图

## 4. 方法概览

- **滑动窗口**：以过去 12 个时间点（2 小时）的 21 维特征作为输入，预测下一时间点 OT。
- **标准化**：Z-score 标准化，仅在训练集上拟合均值/方差，避免信息泄漏。
- **划分**：严格按时间顺序，最后 20% 为测试集，其余部分后 15% 为验证集。
- **基线**：持久化预测（Persistence）、岭回归（Ridge）。
- **模型**：两层 GRU（隐层 128，多种子集成）+ 岭回归；对照组为同结构的 LSTM。
- **融合**：在验证集上选择 GRU 集成与岭回归的最优加权系数（`w*GRU + (1-w)*Ridge`），
  应用到测试集，得到最终预测。
- **训练**：MSE 损失 + Adam 优化器 + 学习率衰减 + 梯度裁剪，验证集早停。

## 5. 实验结果（测试集，原始量纲）

| 方法 | RMSE | MAE | R² | MAPE (%) |
| ---- | ---- | --- | -- | -------- |
| 持久化预测 | 6.2064 | 2.6295 | 0.9287 | 0.60 |
| 岭回归 | 5.8252 | 2.8492 | 0.9372 | 0.65 |
| LSTM | 6.0744 | 3.3841 | 0.9317 | 0.77 |
| GRU 多种子集成 | 5.4277 | 2.7988 | 0.9455 | 0.64 |
| **GRU+Ridge（最终）** | **5.3955** | **2.7629** | **0.9461** | **0.64** |

> 训练固定随机种子（`SEED=42` 及 `GRU_SEEDS=[0..4]`），结果可复现；运行 `python main.py`
> 可在 `results/metrics.json` 复现上表。
